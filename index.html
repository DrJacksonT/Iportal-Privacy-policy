Privacy Policy for iPortal Deep Note Search

Effective date: May 29, 2026

iPortal Deep Note Search is a Chrome extension that provides a local, in-page search overlay for configured iPortal patient notes pages.

Summary: This extension does not collect, transmit, sell, share, or store personal information. Search processing happens locally in the user's browser.

Data Collection

This extension does not collect, transmit, sell, share, or store personal information.

The extension does not send any of the following data to the developer, third parties, external servers, analytics providers, or cloud services:

  • Patient data
  • Clinical note content
  • Page content
  • URLs
  • Search terms
  • Usage data
  • Analytics or telemetry
  • Authentication information
  • Cookies

Local Processing Only

All search functionality runs locally in the user's browser. The extension searches text that is already present in the current web page's Document Object Model, also known as the DOM. Search results are displayed locally in the browser overlay.

Storage

The extension does not store patient-identifiable information, search history, note content, or page content. The extension does not use Chrome storage to save clinical content or search terms.

Network Activity

The extension does not make external network requests. It does not use external APIs, remote scripts, remote fonts, CDNs, analytics tools, or tracking services.

Permissions

The extension is designed to run only on the configured iPortal domain specified in the Chrome extension manifest. Its purpose is limited to displaying a local search overlay and helping users find text already loaded in the current page.

Changes to This Policy

This privacy policy may be updated if the extension's functionality changes. Any updates will be published at this same URL.

Contact

For questions about this privacy policy, please contact the extension publisher through the support details provided in the Chrome Web Store listing or the project repository.
